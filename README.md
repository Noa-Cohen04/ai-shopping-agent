# AI Shopping Agent

**Python | LLM Tool Calling | Semantic Search | AI Agents | Business Logic**

An AI-powered shopping assistant that combines language models, semantic product retrieval, and Python tools to help customers find products, compare options, and receive recommendations based on their needs and store policies.

### Key Features

- **AI Agent:** A custom tool-calling workflow with six tools.
- **Semantic Search:** Sentence Transformers (`all-MiniLM-L6-v2`) and cosine similarity for product retrieval.
- **Product Filtering:** Search by price, brand, availability, and sale status.
- **Customer Authentication:** Demo customer verification and eligibility-based discounts.
- **Business Rules:** Application-level checks for discount eligibility and store policies.
- **Testing:** 18 offline regression checks and a reproducible demonstration.

### Technologies

Python, OpenAI API, Sentence Transformers, NumPy, pandas, JSON, and mongomock.
