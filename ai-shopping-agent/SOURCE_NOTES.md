# Source notes

The agent implementation in `hw4.py` was developed by Noa Cohen as part of
Assignment 4, "Agentic Solution with RAG". The portfolio copy includes the
preparation changes described in the README.

The course supplied the customer-store helper, sample customer structure,
store policies, example queries, and dataset preparation materials. These are
supporting course resources, not claimed as original agent code.

- Course resource reference supplied with the assignment:
  https://gist.github.com/MeirKaD/8da63c754b1dc014847bb0dee1ef3c55
- Catalog origin identified in those materials:
  https://www.kaggle.com/datasets/promptcloud/walmart-product-data-2019
- The included catalog contains 787 rows selected by the course's preparation
  script. Product names, descriptions, and prices are historical sample data,
  not current shopping advice or live inventory.
- Customer names, emails, and passwords were replaced with synthetic demo
  identities; ages were removed. Interests and account statuses remain fixture
  inputs for exercising the agent.
- The assignment PDF is deliberately omitted because it contains course access
  credentials. No license to third-party/course materials is newly asserted by
  this package; their original terms continue to apply.
